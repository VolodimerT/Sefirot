# Проверка Python 3.14.3 в CI

На предыдущем кандидате `3448d95c1aa041a0cf8e06acd229744d4700aca1`
Linux CPython 3.14.3 уже прошёл локальный полный release, установку пакета
с psycopg 3.3.6, CLI demo и native PostgreSQL probe/upgrade. GitHub CI
проверял только Python 3.11 и 3.13. Этот этап добавляет недостающую проверку
в существующий draft PR #56 без изменения приложения или production.

## Матрица

- Ubuntu и Windows: прежние Python 3.11 и 3.13, все прежние шаги сохранены.
- Ubuntu: точная Python 3.14.3, установка `.[sync]`, все тесты, synthetic demo
  и полный `scripts/verify_release.py`.
- Отдельные native PostgreSQL sync и probe/upgrade: Python 3.13 и 3.14.3.
  Каждая задача получает собственный чистый PostgreSQL 16 service container;
  DSN и пароли относятся только к одноразовым локальным тестовым базам.
- Существующая проверка shared-provider-budget остаётся без изменения.

На каждый push и pull_request ожидаются девять задач tests и одна budget;
в сумме 20 результатов на точном HEAD и временном PR merge ref с тем же
деревом. Пропуски шести optional native cases в общей suite допустимы только
при успешных отдельных native jobs: sync 5/5 и probe/upgrade 3/3.
Mandatory WASM/HTTP cases должны выполняться в общей suite.

## Граница результата

Успешный CI подтверждает совместимость этого дерева на тестовых средах,
включая Python 3.14.3. Он не подтверждает текущую конфигурацию или обновление
Render, production SQL, реальные API, независимый HOLDOUT либо преимущество
модели. Hosted SQL и deployment остаются отдельной согласованной операцией.
Протокол, модель, Policy, оригинальные packets/seals/snapshots неизменны.
Режим остаётся RESEARCH_ONLY / PASS / stake=0, новых provider calls — 0.

Точный опубликованный SHA, ссылки на первые CI attempts, результаты и
оставшиеся блокеры фиксируются в итоговом отчёте этапа после выполнения CI.
