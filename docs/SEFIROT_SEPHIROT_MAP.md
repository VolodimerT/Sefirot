# Карта сефир CORE 2.0

| Сефира | Вход → действие → выход | Получатель | Пересчёт / блок |
|---|---|---|---|
| Порог | Матч/формат/время → пригодность → причины отсева | Свидетель | Недопустимый формат или прематчевое окно блокируют |
| Свидетель | Источники и доказательства → хронология, независимость, полнота, конфликты → проверенный snapshot | Сценарий, Вероятность, Оппонент | Новый факт требует ревизии; критические пробелы блокируют |
| Сценарий | Проверенные составы/контекст/история → предпосылки и счётные сценарии | Вероятность, Рынок, Оппонент | Неподтверждённый tactical fit блокирует |
| Вероятность | История без цены и замороженный calibrator → распределения и диапазоны → seal | Рынок после фиксации | Недостаток истории/калибровки блокирует |
| Компетенция | Результаты, рейтинги, контекст, novelty → UNKNOWN/WORKING/WEAK/FROZEN | Арбитр | Слабая/замороженная область блокирует; восстановление только после новых тестов |
| Рынок | Seal + закрытый пул + котировки → выплаты, EV, маржа, сравнение чистоты | Оппонент, Арбитр | Старая цена, неподдерживаемые правила блокируют |
| Оппонент | Доказательства, варианты темпа, цены → конфликты и условия потери основания | Оркестратор, Арбитр | Просит новую ревизию, не создаёт свой прогноз и не голосует |
| Арбитр | Все возражения, компетенция, holdout, политика, портфель → допуск → риск → BET/PASS | Летописец, пользователь | Единственный разрешает; не может снять чужой критический блок |
| Летописец | Все входы/выходы/версии, результат → неизменяемый журнал, replay, метрики, ошибки | Компетенция, версии моделей | Сбой целостности/записи блокирует допуск |

Реализация: `evidence.py` (Порог/Свидетель), `probability.py` и `engine.prepare` (Сценарий/Вероятность), `feedback.py` (Компетенция), `markets.py`, `engine.decide` (Рынок/Оппонент/Арбитр), `risk.py`, `repository.py` и `service.py` (Летописец и оркестрация). Это распределение обязанностей, не отдельные серверы и не девять языковых моделей.
