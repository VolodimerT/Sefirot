## Восстановленные функции и исправления

1. Восстановлены восемь ARENA-ролей, разделение sports/priced, привязка к исходному seal, воспроизводимые findings, реестр create-once и исследовательский scorecard. V3 ablation остаётся отдельной процедурой сравнения моделей. ARENA не подключена к серверу, Worker или admission.
2. Старый тест ожидал, что Repository пропустит изменение SQL-идентификатора. Действующий CORE отклоняет его при сверке SQL identity, FK, времени и payload. Проверка исходного прогноза и решения теперь выполняется в одной read-only транзакции с явной сверкой fixture ID решения. Повторный обход журнала удалён.
3. Prediction Edge сообщает об отсутствии допущенных исходных рядов. Предыдущий текст объявлял отсутствующим уже существующий read-only адаптер. Регрессия проверяет нулевой подтверждённый HOLDOUT и закрытый допуск.

## Валидация моделей

В каждой строке сравниваются одинаковые матчи и одно определение Brier. Шкалы и состав исходов различаются между строками.

| Проспективный Prediction Edge DC / SOS | 0 подтверждённых | — | — | Для новых пар нет оригинальных входов |

Повторный расчёт P0 совпал для всех семи рынков. Brier кандидата улучшился в трёх и ухудшился в четырёх. Архивный DQ replay по сохранённым CSV до 25 ноября воспроизвёл SHA-256 c60f5f91c3502fa32a01ffe22842db7dc818530d776a38ee02d39469db66939b. Время матчей и сохранённые исходы подтверждают хронологический replay. Для независимого HOLDOUT ещё нужны predeclared набор, оригинальные квитанции приёма и подтверждённые исходы.

C2 вернул INPUTS_MISSING_OR_REJECTED. Нужны оригинальные календарь и архив квитанций, checkpointed SQLite и W1. Восстановленные ARENA-отчёты исключены из эмпирического сравнения.

Точные результаты опубликованы в Draft PR.

- Для отката на временной review-ветке от HEAD выполнить git revert --no-commit 8346bb4..HEAD, сверить staged tree с 8346bb4^{tree}, затем зафиксировать откат. Отдельной обратной SQL-миграции для этой дельты нет.
