# Диагностика API-бюджета: независимая проверка PR #70

Проверен точный исходный head `734c15a9c71995f9ac63711b839ef0447f166a82`.
Оба CI события упали; шесть остальных matrix jobs отменены fail-fast. Это
не результат успешной проверки API, очереди или исчерпания квоты поставщика.
Причина: тест передавал _Opener вместо callable _Opener.open. На исходном
коде локально воспроизведены 9 errors в трёх методах новых gateway-тестов.

Исправлен тестовый адаптер без изменения интерфейса get_sports. Проверяются
закрытие ответа и ровно один вызов. Добавлены шесть методов: неоднозначный
ok, неправильный тип причины, настоящий urllib HTTPError 429, полный путь
HTTP -> sports_probe, путь HTTP -> api-health и невалидный конструктор.
На исходной логике после исправления адаптера новые проверки воспроизвели
2 assertion failures и 2 errors. В api-health терялся новый тип budget denial;
теперь фиксированный код SHARED_BUDGET_* сохраняется. Реальная ошибка доступа
401/502 и неизвестная причина не становятся отказом бюджета. Классификация
возможна только при HTTP 429, ok=false, SHARED_BUDGET_STOP и известном enum.

33/33 профильных теста: 9 budget +5 probe +19 health. Настоящие провайдеры,
секреты и production не использовались. Полный release/CI и точный SHA
фиксируются в отдельном отчёте. Изменение только диагностики не включает
квоту и не подтверждает подписку, provider quota или денежный допуск.

Текущий production проверен только на чтение 15.10.2026 около 08:10 UTC:
бюджет PAUSED, enabled=false, remaining_day=0, reserve_day=5, valid_until=null,
in_flight=false, attempts_today=0. Render повторно развёрнут другим этапом
07:38 на прежнем коде 7d756d3e; рестарт не включает защищённый бюджет.
Мы не выполняли повторного restart/deploy, budget UPDATE, reserve/finish RPC
или provider request. Историческая инструкция со скриншота не считается
результатом выполнения SQL или доказательством текущего доступа к API.

После ремонта существующего #70 диагностика переносится в единый кандидат
#56 с сохранением новых проверок полноты HTTP и безопасного cleanup.
Старые seals/decisions/receipt/fit/approval не переподписываются. Полный
источник/CAL/HOLDOUT/модельное преимущество не подтверждены: PASS, ставка 0.
