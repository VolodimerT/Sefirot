## Подтверждённые исправления

1. `work` возвращал exit 0 даже при ERROR задания. Теперь ошибка даёт 2
   и в JSON, и в текстовом режиме. PASS решения не путается с ошибкой программы.
2. Действие Service коммитилось раньше receipt задания. Сбой между ними
   мог оставить действие без receipt. Теперь одна внешняя транзакция
   включает действие, receipt и audit; внутренние транзакции — savepoints.
   Проверены rollback CAPTURE/DECIDE/RESULT/CLOSING, вложенный rollback и retry.
   Busy COMMIT при втором SQLite reader также откатывается: pending записи
   не выдаются за уже сохранённое задание.
3. Новые receipts jobs получили content-bound audit. Подмена receipt
   блокирует очередь. Старые receipts сохраняют прежнюю область доказательства.
4. Просмотр `accounting/report/replay/compare` мог создать пустой журнал
   и выполнять bootstrap. Теперь только существующая read-only БД.
   `backtest` больше не создаёт журнал, который ему не нужен.
5. Упрощён существующий `work`: короткая карточка, повторный показ записанного
   решения, обычная справка, default main pool, ссылка на CAPTURE по job ID.
   Новый параллельный runtime или денежный путь не добавлен.

Документация ежедневного локального пути: [OFFLINE_WORKFLOW.md](OFFLINE_WORKFLOW.md).
Sports seal предшествует открытию файла цены; готовые цены не становятся
новыми наблюдениями. Нет сети, auto bet, LIVE, догона или новых разрешений.

## Реальная оценка эффективности

`scripts/audit_frozen_effectiveness.py` восстановил полный архив P0 по
исходному SHA-256 и заново посчитал Brier/log loss/ECE из original frozen
probability vectors. Все прежние метрики воспроизведены до 1e-12.
Оцениваются **380 исторических fixtures**, уже просмотренный TEST. Рынки
одного матча не независимы; нового holdout или refit не было.

SoS/count кандидат лучше BASELINE по Brier на **3/7** рынков, хуже на **4/7**.
На первичном ИТБ хозяев 1,5: 0.244757 → 0.237599, delta −0.007158.
Описательный интервал [−0.019701; +0.005384] включает ноль и не учитывает
зависимость матчей. ECE macro ухудшился 0.055356 → 0.067133.
Итог **KEEP_SHADOW**. Нет основания переключать default или подбирать
пороги по просмотренному TEST. Davidson архив — другая историческая модель,
её результат нельзя приписывать текущему BASELINE.

Новые независимые проверки арифметики: 49 пар интенсивностей от .01 до 12,
closed-form BTTS/тоталы, complementary contracts с PUSH, 200 fair-price/EV
случаев, известные uniform/perfect/wrong scores, три de-vig метода.
Они проверяют реализацию, не предсказательную силу модели.

## Следующие идеи по приоритету

1. **Простой экран импорта и очереди.** Sports → seal → price/recheck →
   карточка → результат; один статус и следующее действие. Он вызывает
   тот же Service, не содержит второго расчётного ядра.
2. **Предварительно замороженная оценка.** Одна полная будущая cohort,
   primary market/metrica, TRAIN/TUNE и отдельная unseen HOLDOUT,
   reliability bins и зависимости матчей. Technical min_holdout не
   считать обоснованным объёмом выборки. В этом продолжении сбор не запускался.
3. **Один model challenger.** Например Dixon–Coles для low-score dependence;
   neutral venue при пригодных данных. Сначала shadow experiment против
   прежнего BASELINE; default только после нового замороженного теста.
4. **Производительность session на больших журналах.** Измерить стоимость
   многократного чтения feedback/context и только затем менять индексы/
   batch reads. Не кешировать journal_ok или разрешения вместо свежих bytes.
5. **Малые рынки после основного пути.** Один count market с own line
   calibration. Фолы не заменяют ЖК; карточки только через Referee Gate.

Новый большой набор рынков, Builder и дополнительные агенты сейчас не
решают главного ограничения. Новые сильные проценты без validation
только создадут ложный EV. Денежный статус — **пропуск, класс D** до gates.
