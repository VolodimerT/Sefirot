# SEFIROT — общие правила аудита

Конституция проекта имеет приоритет над исследовательскими предложениями. Проверяемые правила ядра:

- Внешний сигнал, собственный расчёт и фактический купон записываются отдельно.
- Предматчевые решения не используют поздние сведения и котировки до seal вероятности.
- Отсутствие вероятности, WAIT с владельцем и сроком и PASS имеют разные причины.
- Повторная экспозиция на один матч блокируется; фактическое нарушение сохраняется лишь как историческая запись.
- LIVE и EXPRESS не получают допуска; малые рынки оставлены на доработку.
- Счётные ветви проверяют, может ли составной рынок проиграть при верной общей гипотезе; без количественной вероятности такая проверка не вычисляет EV.

Предложение брать вероятность из линии как исходную величину противоречит правилу независимого прогноза. В текущей версии линия запрашивается только после seal. Иллюстративная модель не калибрована, вывод о положительном EV на реальном рынке не подтверждён. Здесь нет персональных купонов или истории пользователя.
