# Следующий frozen ARENA experiment

Статус DRAFT, не зарегистрированный опыт. API-пауза сохраняется. До сбора
закрепить manifest независимым timestamp receipt; нынешние JSON/SQLite
этого не заменяют. Просмотренный 380 TEST не новый prospective holdout.

Unit: fixture, один hypothetical single per arm. До исходов выбрать точные
лиги/профиль/период/источники/sample size и способ внешней фиксации; сейчас
они не выбраны, опыт не начат. Зарегистрировать полную eligible cohort
REGULATION_90 без требования prediction. Привязать original sports seal,
Service decision и quote/recheck receipts до kickoff. Пропуски не backfill.

Три arms на exact prediction/pool/cutoff/price: original saved decision,
naive max EV≥2%, frozen RULE_ONLY screen. Версия/thresholds до исходов;
exceptions/missing навсегда в denominator. Outcome — после finish/received
с receipt. Actual execution/CLV — отдельные records, не hypothetical прибыль.

Primary: paired hypothetical ARENA−original unit profit per planned fixture,
с раскрытием missing arms/results. Secondary: coverage, rejected profitable/
unprofitable (hindsight), selection ROI с bias note, Brier/ECE unchanged P
через Core forward-scorecard. Date/league/profile/exact market/line strata;
sparse bins insufficient. LLM tokens/cost/latency=null до measured adapter.
Economic utility = avoided errors − missed opportunities − measured cost;
не складывать разные units без declared conversion.

30 settled/8 dates — exploratory only. Ориентир серьёзной проверки ≥300
paired eligible, ≥80% coverage и отдельный нетронутый future holdout; числа
сами по себе не дают денежного допуска. Stop: integrity/time/provenance
failure, provider refusal, budget, incompatible build, population shift.
Не заменять плохой участок/лиги и не подгонять thresholds по его исходам.

Следующий P1 минимум: replayable live LLM adapter с max calls/tokens/USD,
timeout, no retry storm, sanitized error/request receipts; сравнить
RULE_ONLY vs LLM_SHADOW costs. Оплачиваемые вызовы требуют отдельного
поручения; сейчас их 0. Роли 1→3→8 — после замера пользы. Causal tests,
Referee Gate для ЖК, correlation/parlays и Dixon–Coles — отдельные будущие
preregistered расширения; не менять Policy/модель ради демонстрации.
