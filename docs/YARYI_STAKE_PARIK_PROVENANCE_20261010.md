# Протокол источников для сравнительного журнала — 10.10.2026

## Строгое правило пользователя

- **Stake (скриншоты первоначальных рекомендаций)** = **Ярый**, исходные предложения и гипотетический исход. Не считать Stake реальным денежным исполнением пользователя, пока не предоставлено доказательство ставки на Stake.
- **Parik24 (рассчитанные купоны)** = **наши реально исполненные ставки**, вне зависимости от того, предложил рынок ранее Ярый или это новая идея.
- Если наш Parik24 купон совпадает с рекомендацией Stake, выставлять связь `COPIED`. Если коэффициент, рынок или ноги Builder изменены — `MODIFIED`. Если независимый выбор подтверждён — `INDEPENDENT`. Иначе `UNKNOWN`, не угадывать.
- Результат Stake рекомендации = рекомендательная точность Ярого, **не ROI и не финансовый P&L**, если реальное размещение у него не подтверждено.
- Выигрыш/проигрыш Parik24 = финансовый результат **нашей стратегии**, не доказательство качества необнаруженных модельных вероятностей. Не смешивать с прогнозами непосредственно запущенного SEFIROT CORE без prematch seal.
- При сравнении использовать одни и те же матчи, проверенные исходные рекомендации, не допускать множественного подсчёта связанных рынков как независимых предсказаний.
- В течение дня вести журнал новых скриншотов и изменений. Один итоговый аудит после закрытия дня; отдельно Ярый/Stake, наши Parik24, совпадения/изменения/отказы, расхождение банка и купонов, суммарный риск по одному матчу.

## Где хранится

В Supabase `sefirot.manual_source_comparison` (PRIVATE, RLS), отдельно от оригинального канонического журнала вероятностей. Поле `model_probability_verified=false` запрещает принимать ручной ретроспективный результат за настоящий предварительный прогноз CORE. Источник Stake всегда recommendation без stake/payout; Parik24 может иметь stake/payout.
