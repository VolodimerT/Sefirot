# Ответ на Cross Audit от 2026-09-27

Аудит изучал публичную v0.7, commit f71b882. Этот документ относится к локальной CORE 2.0.0. Замечание о разнице между программной работоспособностью и доказанным прогнозным преимуществом принято полностью.

## Что изменено по аудиту

| Требование | Выполненное действие | Ограничение |
|---|---|---|
| Реальный набор одной лиги | 1900 матчей АПЛ, сезоны 2020/21–2024/25; manifest с SHA256 и URL | CSV не содержит достоверных receipt timestamps; исследовательский импорт хранит null, не выдумывает время |
| Хронологическая проверка | 760 TRAIN → 380 TUNE → 380 CALIBRATE → 380 TEST | Ретроспективное предположение: результаты предыдущего календарного дня уже доступны |
| Обучаемая модель | 54 фиксированных комбинации Elo K/home advantage/Davidson draw/season regression; выбор только по TUNE LogLoss | Абсолютный начальный рейтинг 1500 — начало шкалы, его нельзя идентифицировать отдельно из результатов |
| Модель ничьей | Davidson; отдельный baseline прежней эвристики ничьей | Poisson/Skellam не включён в этот сравнительный эксперимент; не заявляется проверенным |
| Калибровка | Temperature scaling на отдельном сезоне; Brier/LogLoss, classwise reliability/ECE, sharpness/entropy, месячные отчёты | Оптимальная T=1.0, то есть улучшения калибровкой здесь нет |
| Baseline | Исторические частоты, старый Elo, модель, линия Avg без маржи, closing reference | Closing используется только для последующей оценки, не для обучения или отбора ставки |
| Devig | Явные proportional/power; утилита multi-book consensus/dispersion/best price | Shin не реализован; multi-book утилита не подменяет независимую спортивную P и не выбирает исполнимую цену автоматически |
| CLV | Сопоставление B365/B365C, odds CLV и движение fair P | B365 — pre-closing snapshot, не доказанная цена исполнения/самая первая opening |
| Риск | Flat capped stake, понижение при просадке, все exposure-лимиты; Kelly только диагностический | Политика исследовательская, не одобрена для реальных денег |
| Воспроизводимость | dataset hash, code hash, параметры, split, все TEST P и результаты, run_id; запрет перезаписи output | Локальный файл не является внешним неизменяемым реестром; новый путь не предотвращает исследовательскую недобросовестность |
| Границы диапазонов | Явно отделены Wilson/bin uncertainty и stress envelope | Это не доверительный интервал индивидуальной истинной P; coverage не выдумывается из 0/1 результатов |
| Продвижение | Исследовательский отчёт не может активировать модель CORE и не создаёт release token | Прогнозная модель остаётся EXPERIMENTAL |

## Результат финального теста — 380 матчей 2024/25

Brier использует нормировку multiclass /2, меньше — лучше.

| Метод | Brier | LogLoss | Macro ECE |
|---|---:|---:|---:|
| Исторические частоты | 0.3273 | 1.0799 | 0.0177 |
| Прежний Elo | 0.2979 | 1.0002 | 0.0531 |
| Обученный Davidson + T=1 | 0.2995 | 1.0009 | 0.0629 |
| Avg pre-closing, proportional | 0.2894 | 0.9706 | 0.0416 |
| Avg pre-closing, power | 0.2898 | 0.9710 | 0.0363 |
| Avg closing, reference only | 0.2876 | 0.9667 | 0.0393 |

Новая модель не победила старую Elo или букмекерскую линию. Малый ECE частотного baseline не означает высокую полезность: его Brier и LogLoss хуже. Диагностическая flat-stake симуляция с EV≥2%: 312 условных ставок, −30.27 единицы, yield −9.70%, максимальная просадка 40.78 единицы; средний odds CLV +1.49%. Это пример, почему положительный средний CLV отдельно тоже не доказывает прибыльность. Комиссии, лимиты и реальное исполнение не моделировались. Деньги не размещались.

После просмотра TEST параметры не подбирались заново. Прогон сохранён, а не заменён более красивым результатом. Следующая модель должна проверяться на новом заранее назначенном периоде; этот сезон теперь исследователю известен.

## Что остаётся открытым

- Нет проспективной истории с проверяемым временем получения данных и реальным исполнением.
- Нет подтверждённого преимущества модели; автоматическая денежная активация не выполнялась.
- Research Davidson не заменяет тихо основной goals-gamma-v1: модели разделены, у них разные области проверки.
- Тактические факты, составы, травмы и reliability источника вводятся извне; программа не умеет сама доказать правдивость этих полей.
- Продвинутая тактика/LLM, автоматический сбор live-источников, Shin, обученная неопределённость и надёжная coverage требуют отдельной проверки. Они не заявляются готовыми.
- D1 экспрессы и D2 малые рынки остаются отложенными по Foundation. LIVE и догон отсутствуют.

## Данные и воспроизведение

Первичный источник: https://www.football-data.co.uk/downloadm.php . Поставщик различает pre-closing и closing данные с 2019/20. Исходные CSV не включаются в публичный исходный код; в `reports/DATA_MANIFEST.json` есть официальные URL и контрольные суммы. Сохраните пять CSV локально, затем:

```powershell
py -3 sefirot.py research E0_2021.csv E0_2122.csv E0_2223.csv E0_2324.csv E0_2425.csv --output data/reproduction.json
```

Повтор на тех же данных воспроизводит вычисления, но не становится новым независимым тестом. Полный оригинальный результат: `reports/REAL_DATA_BENCHMARK.json`.
