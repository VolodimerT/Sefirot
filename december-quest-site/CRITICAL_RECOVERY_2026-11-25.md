## Запуск и изоляция

```sh
node autonomous/paper-cli.mjs DAILY_PAPER_TEST YYYY-MM-DD verified-calendar.json paper-output.json
node autonomous/paper-cli.mjs HISTORICAL_REPLAY YYYY-MM-DDTHH:MM:SSZ competition-codes.json replay-output.json
```

Команды выполняются из `december-quest-site/`. `DAILY_PAPER_TEST` принимает список матчей с UTC или явным смещением времени, `timing_status`, `checked_at` и двумя разными HTTPS-источниками для подтверждённого kickoff. Сверку источников выполняет оператор входного календаря. Проверки исключают уже начавшиеся матчи, ближайшие 20 минут до старта, дубли, неподтверждённый старт и неподтверждённую модель. История загружается из разрешённых провайдеров. `HISTORICAL_REPLAY` ограничен CLI и помечен как неперспективный архивный пересчёт. Для дат без кандидатов ответ `NO_UPCOMING_FIXTURES` и PASS.

Изолированный Edge `dq-paper-test-v63` принимает только `DAILY_PAPER_TEST`. GET возвращает флаги работоспособности, POST требует существующий закрытый токен, который проверяет прежняя Supabase RPC. Секреты передаются на сервере. Функция не записывает в базу и не имеет своего расписания. `DECEMBER_QUEST` использует свой существующий календарь, Edge и cron. Откат Paper заключается в отключении отдельного Edge и откате feature-коммита.

Для timestamped odds используется прежний `odds-gateway.js` с отдельной картой из 19 документированных кодов провайдера для Paper. Допуск модели требуется до запроса котировки. Для УПЛ подходящий код поставщика отсутствует. Достоверная строка требует совпадения лиги, команд, kickoff, рынка, линии, правил и времени котировки. Статический CSV остаётся источником диагностики. Edge хранит ключ источника в существующей переменной `DQ_ODDS_API_FREE_KEY`, бесплатный ключ в проверенном окружении отсутствует. Автоматическое получение глобального дневного календаря и контекст v21.2 не закрыты. Paper блокирует рекомендации при этих пробелах. Это ограничение проверенного допуска, включая сценарий, в котором поставщик вернёт допустимый коэффициент. Для принятия экспрессов нужны проверенные контекстные фильтры, рабочая котировка и тест корреляции.
