## Допуск моделей

Для ЛЧ сравниваются прежний Elo, клубный Elo с межтурнирной историей и Poisson с раздельными оценками атаки и обороны. Последний вариант обновляет оценки по фактическим голам относительно ожидаемых от конкретного соперника. Сила ассоциаций рассчитывается по международным встречам. Домашний эффект оценивается в соревновании. Матчи обучения идут строго до дня прогноза UTC. Квалификации используются только в обучении, оценки сравниваются на лиговой фазе. Национальные данные не переносятся в еврокубки. DFB-Pokal получает собственную историю и отдельное состояние модели. Неопределённость улучшения над baseline подсчитана по календарным дням. Пороги допуска прежние. Кандидат выбирается по архивному Log Loss после прохождения архивных порогов, свежая выборка имеет право вето.

## Котировки и контекст

Для Paper сохранены точные правила матча, рынка, линии и расчёта, добавлены обязательный ID события, проверка разумности маржи, явное указание области provider timestamp, различение `NO_VERIFIED_PRICE`, `NO_EDGE` и `FRAGILE_EDGE`. Средняя рыночная цена представлена медианой, EV использует фактически доступную цену и вероятности всех исходов расчёта. Реальная проверка цен блокируется отсутствием бесплатного ключа. Владелец выбирает **Starter / Free** на [The Odds API](https://the-odds-api.com/#get-access), затем сохраняет полученный по email ключ под именем `DQ_ODDS_API_FREE_KEY` в [секретах Supabase Edge этого проекта](https://supabase.com/dashboard/project/kxqpwgwihtjmqlcxgfxp/functions/secrets). Значение в чат передавать не требуется. Тариф даёт 500 кредитов в месяц. Закрытый спортивный gateway v18 по конфигурации принимает `fixtures`, `injuries` и `fixtures/lineups`. Endpoint котировок там не разрешён.

Для Paper включён путь чтения из существующего gateway через `DQ_AUTHORIZED_GATEWAY_RUNNER_TOKEN`. Он требует разрешённого runner-токена и доступного бюджета. Сверяются ID соревнования, команды, `NS` и kickoff, а для контекста также временная метка поставщика. Возвращаются факты о рефери, травмах, подтверждённых составах и схемах при наличии. В проверенном окружении токен Paper не настроен. Серийная статистика ударов, ударов в створ, угловых, фолов и карточек доступна в 7 внутренних модельных матчах. Тактический fit, дисквалификации, Public Trap и Referee Gate остаются открыты. Для автоматической интеграции [Sofascore не предоставляет sports data API](https://sofascore.helpscoutdocs.com/article/129-sports-data-api-availability?lng=en).
